# 关于我

你好,我是 **Sunny** 👋

一名 Java 后端开发者,目前主要写 Spring Boot,也在学 Redis 缓存、MyBatis-Plus 和消息中间件这条路上的各种东西。平时喜欢把项目里踩过的坑整理成文章——于我而言,写复盘是最好的复盘。
